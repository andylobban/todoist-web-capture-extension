# Privacy policy draft

Todoist Better Extension only sends data to Todoist when the user explicitly triggers a save.

## Data handled
- Current page title
- Current page URL
- Todoist OAuth tokens returned to the extension after sign-in

## Purpose
- Create a Todoist task from the current page
- Maintain the signed-in session so the extension works without repeated sign-ins

## Storage
- Access tokens are kept in extension session or local storage as needed for operation
- Refresh tokens are stored in extension-controlled local storage
- No analytics or third-party tracking are included in this V1 scaffold

## Sharing
The extension sends capture data only to Todoist's API endpoints needed for authentication and task creation.
